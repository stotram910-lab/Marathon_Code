# Marathon Distance Calculator (C)

A simple C program that converts the official marathon distance from miles and yards into kilometers.

## Concepts Used

- Variables
- Integer and Double Data Types
- Arithmetic Expressions
- printf()
- Basic Unit Conversion

## Formula

Kilometers = 1.609 × (Miles + Yards / 1760.0)

## Example Output

```
A marathon is 42.185969 kilometers.
```
